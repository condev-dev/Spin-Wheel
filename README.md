**Spin Wheel** – A lightweight, interactive, and fully responsive spin wheel application.  
Built with **HTML, CSS, JavaScript, jQuery, Bootstrap, and Flexbox**, crafted for **smooth animations, polished UX/UI, and fully customizable interactions**.

## ✨ Key Features

> Developed with **Senior Front-End principles**, focusing on **smooth animations, interactive UX, and fully customizable functionality**:

- 🎯 **Random Spin Selection** – Wheel segments can be determined dynamically  
- 🏆 **Pop-Ups for Win/Loss** – Instant feedback with secondary pop-ups for guidance  
- ⏰ **Daily Spin Limit** – Users can spin 3 times per 24 hours  
- 🎨 **Fully Customizable Items** – Colors, labels, icons, and probabilities configurable  
- 📱 **Responsive Design** – Optimized for mobile, tablet, and desktop  
- ⚡ **Smooth Animations & Micro-Interactions** – High-quality UX/UI polish  
- 🛠 **Clean & Modular Code** – Easy to extend, maintain, and integrate
